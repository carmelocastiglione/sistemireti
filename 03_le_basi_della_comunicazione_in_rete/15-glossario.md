# 15. Glossario

| Termine | Definizione |
|---|---|
| **ASK** | Modulazione digitale che rappresenta i simboli variando l'ampiezza della portante |
| **Bandwidth** | Ampiezza di banda in frequenza, oppure capacità nominale del collegamento nel linguaggio delle reti |
| **Baud** | Unità che misura il numero di simboli trasmessi al secondo |
| **Bit rate** | Numero di bit trasmessi al secondo |
| **Canale** | Percorso o risorsa attraverso cui si propaga un segnale |
| **CRC** | Codice a ridondanza ciclica usato per rilevare errori |
| **Demodulazione** | Ricostruzione dei simboli dal segnale ricevuto |
| **Duplex** | Modalità di comunicazione nelle due direzioni |
| **FDM** | Multiplexing che assegna bande di frequenza distinte ai flussi |
| **Fibra ottica** | Mezzo che trasporta informazioni mediante luce |
| **FSK** | Modulazione digitale che rappresenta i simboli variando la frequenza |
| **Hamming** | Famiglia di codici in grado di correggere errori singoli |
| **Multiplexing** | Condivisione di una risorsa di trasmissione tra più flussi |
| **NRZ** | Codifica in linea in cui il livello non torna a zero durante ogni bit |
| **Packet switching** | Trasferimento di dati suddivisi in pacchetti su collegamenti condivisi |
| **Parità** | Bit ridondante che permette di rilevare alcune alterazioni |
| **PSK** | Modulazione digitale che rappresenta i simboli variando la fase |
| **QAM** | Modulazione che varia ampiezza e fase della portante |
| **RZ** | Codifica in linea in cui il segnale ritorna a un livello di riferimento entro il bit |
| **Simplex** | Comunicazione in una sola direzione |
| **TDM** | Multiplexing che assegna al flusso intervalli di tempo |
| **Throughput** | Quantità di dati utili consegnata nell'unità di tempo |
| **Twisted pair** | Cavo formato da coppie di conduttori intrecciati |
| **WDM** | Multiplexing di flussi su lunghezze d'onda distinte in fibra |
