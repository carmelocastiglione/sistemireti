# 13. Tabella riepilogativa

| Argomento | Concetto fondamentale |
|---|---|
| Segnale analogico | Può assumere valori continui |
| Segnale digitale | Rappresenta l'informazione con un insieme finito di simboli |
| Modulazione | Associa i simboli a variazioni della portante |
| Demodulazione | Ricostruisce i simboli dal segnale ricevuto |
| ASK | Modula l'ampiezza |
| FSK | Modula la frequenza |
| PSK | Modula la fase |
| QAM | Modula ampiezza e fase |
| TDM | Condivide il canale nel tempo |
| FDM | Condivide il canale in bande di frequenza |
| WDM | Multiplexing per lunghezze d'onda in fibra |
| NRZ / RZ / Manchester | Schemi di codifica in linea |
| Throughput | Quantità di dati utili consegnata per unità di tempo |
| Parità | Rileva alcuni errori, ma non li corregge |
| CRC | Rileva efficacemente molte forme di errore |
| Hamming | Può correggere errori singoli |
| Twisted pair | Coppie di conduttori intrecciati |
| Coassiale | Conduttore centrale e schermo concentrico |
| Fibra monomodale | Un modo di propagazione; adatta a collegamenti lunghi |
| Fibra multimodale | Più modi di propagazione; usata spesso su distanze più brevi |
| Wireless | Trasmissione nello spazio con onde elettromagnetiche |
| PSTN / ISDN | Tecnologie storiche di rete telefonica |
| xDSL | Trasmissione digitale broadband su doppino |
| FTTx | Fibra fino a un punto definito dell'accesso |
| Circuit switching | Riserva un percorso o risorse per la sessione |
| Packet switching | Trasferisce pacchetti su collegamenti condivisi |
